# TARA 14.2.2 — verified trailing saves and evidence sync

Includes 14.2.0 and 14.2.1. The isolated reload test exposed a pre-existing throttle that discarded a cloud-restored log arriving within 2.5 seconds of the initial empty save. Persistence now schedules the latest update for the end of that interval instead of dropping it. A new update cancels and replaces the pending save; the existing leave-page emergency save remains intact.

Cloud sync now recognizes changes to original decisions, corrections and official evidence even when the window count and resolved count are unchanged or decrease. Previously that optimization could skip corrected records. No trading policy or order behavior is changed by this follow-up.
