# TARA 14.3.1 — missing-funding neutrality

Final 14.3 verification found an edge case: missing current funding could be compared as zero against a known historical rate. Both engine consumers now require an observed current rate before deriving a funding change. Missing history also produces no invented change. A genuinely observed zero rate remains valid.

The same official-calendar and market-intelligence release remains intact; no stake, execution, arming or account-permission change. All 47 tests and the production build pass. See 14.3.0 for scope and documented free-source limitations.
