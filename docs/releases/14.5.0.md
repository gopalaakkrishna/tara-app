# 14.5.0 — approved interface implementation

Implements the approved v14.5 Sites design in the production Tara application.
Sites remains a visual prototype; production is Cloudflare Pages at
https://taracalls.pages.dev, sourced from gopalaakkrishna/tara-app main.

## Interface and coverage

- TARA star, charcoal/gold styling, consistent spacing, typography and mobile
  layouts. Fonts are self-hosted with their open-font licenses.
- Overview: live reference price, verified Kalshi strike, real window timer and
  executable quote; a separate captured Call and Call-record/recent-results
  panel; compact execution status; the original TradingView chart and market
  outcomes; hourly record shortcut. Full control room remains available.
- AutoTrade: input Call, order, verified-or-unverified exchange position and
  execution mode stay distinct. Lifecycle, account controls, fill evidence,
  reconciliation, other open positions, read-only account audit, trade coach,
  manual controls and scalper remain available. New live entries stay paused.
- Signals: compact tape/depth and trend/timing view with live gates, plus all
  original detectors and controls in a disclosure. Original panels remain
  mounted when the disclosure or visual tab changes.
- Hourly: pending picks or a qualifying candidate, chosen-side model, captured
  signal score, price, estimated net edge and actual confirmation sequence.
  All open picks, native strike ladder, record, exports, settings and schedule
  remain available. Historical captures without approval data stay unavailable.
- Memory: separate Calls/hourly ledgers; recorded-version and outcome filters;
  keyboard-accessible capture inspector. Original reason, blocker/gate, quote,
  capture time, remaining time, version and settlement provenance are retained.
  Existing full record, learning, export and amendment controls remain reachable.
- Analytics: scoped version/window cohorts, timing and observed-confidence
  results, exact captured blocker examples and explicit missing evidence. The
  estimated per-contract return requires original quotes and a consistent
  matching official settlement; it excludes amendments and is not AutoTrade
  P&L. Existing deeper analyses, heatmaps and learning/research remain available.
- Brain: captured explanation stays separate from changing live evidence;
  original signal ledger and model diagnostics remain in the expanded view.
- Sports: stable overall counts and distinct upcoming, tracked, settled and all
  fixture lanes. Detailed fixtures, sport/date filters, comparison, readiness,
  experiments and disclosures are retained without repeating the same board
  at full size by default. Prices remain labelled snapshots.
- Weather: clear live/paper/settled lanes, separate records, city selector and
  concise live status. Full bucket ladder, city forecast, history, methodology
  and basis-risk disclosures remain available. Weather logic is unchanged.
- TradingView, News & macro, Tools & sync and existing utility/settings panels
  retain their actual data sources and actions.

## Preserved behavior

The 15m seven-minute cutoff, all lock thresholds, timing/price/sample/cooldown
rules, hourly probability/confirmation/admission functions, settings/defaults,
AutoTrade entry/exit handlers and live-money entry pause are unchanged. The
Call and hourly policy modules change only their version strings. No production
records, thresholds, account credentials or persisted user settings were edited.
Cloud-status availability is not presented as acknowledgement of a specific
record. No new prediction, execution, settlement or profitability claim is made.

## Verification

Full automated suite: 212 tests, including the production decision lifecycle,
restoration, sync, hourly admission, settlement and new display-evidence tests.
Production build succeeds. Source comparison against c5e4ecf verified the Call,
posterior, hourly model, hourly confirmation prefix, coordinated lifecycle and
AutoTrade entry/exit paths unchanged, alongside the integrity/sync modules.

Browser checks mount the actual application only at the isolated test URL
http://127.0.0.1:4186/tests/visual/v145.html. All off-origin parent-app requests
are intercepted, account credentials are absent, writes cannot reach production,
and the banner clearly identifies canned data. The fixture is outside the
production Vite input. Checked main and utility views, version filtering,
captured sit-out/approval inspection, Sports counts, Weather lanes, settings,
original expanded controls, desktop1440 and mobile390 layouts. The original
TradingView iframe remains a third-party read-only chart; its remote availability
and intermittent widget/telemetry errors are not an application regression test.

Deployment completion requires the exact pushed commit's Cloudflare Pages check
and the public site's served bundle/version, not the GitHub redirect workflow.
No active live trading tab is reloaded during verification. Runtime locking and
new cloud settlements after the user loads this release remain separate from
UI/build verification. Roll back this presentation commit if controls become
inaccessible, evidence changes, or the app fails to render; preserve all data
and the execution pause through rollback.
