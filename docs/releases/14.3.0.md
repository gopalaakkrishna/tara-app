# TARA 14.3.0 — official market intelligence

## Delivered

- One live BLS / BEA / Federal Reserve schedule replaces the two conflicting approximate calendars. CPI, payrolls, PPI, GDP, personal income/PCE and published Fed events use published dates and times, including actual Eastern daylight-saving transitions. Existing macro widgets and confidence/guard paths read the same schedule.
- The News & macro page includes an upcoming-events list, linked official sources, expandable source health and external Koyfin Free / FRED / optional OpenBB research links. The TradingView chart and existing navigation/controls remain.
- Each calendar source is independently cached in the Cloudflare Cache API for one hour; last-good data is retained for 24 hours but labeled stale and excluded from active guards on a failed refresh. A schedule older than six hours cannot be treated as fresh by the client. Missing coverage is UNKNOWN, not an all-clear. The client refreshes every five minutes and on tab visibility return.
- Bounded fixed-host reads, timeouts, size limits, GET-only handlers, no new credentials or subscriptions. Worker runtime tested locally with Wrangler 4.141.0; a runtime-incompatible redirect option was corrected to manual/no-follow. A descriptive Tara User-Agent is required by the BLS source in the Workers runtime.
- Kalshi's active-window reader uses the public first-party endpoint, with one same-origin exchange fallback. It no longer eagerly sends seven parallel requests through third-party CORS relays. The public proxy rejects account paths, traversal and non-GET methods; authenticated execution routes are unchanged.
- Existing Coinbase, Kraken, OKX and Bybit comparison feeds now distinguish exchange timestamps from receipt-only timestamps, reject dated price ticks and avoid overlapping requests. No duplicate market poller was added. Failed/replayed responses do not refresh spot health.
- The old `useBloomberg` implementation is now `useDerivativesData`: its source is OKX, not a Bloomberg subscription. Seven derivative groups are validated independently. All failures cannot masquerade as live data; missing groups are neutral/unavailable rather than retained live values. Zero funding is valid, absent funding history is not zero, and top-trader positioning is no longer fabricated from an all-account ratio.
- Live Feeds displays missing fields as unavailable and labels the five-minute OI history warm-up. Resting book liquidity is not described as confirmed liquidations. The cross-exchange price reference is explicitly not licensed CF BRTI.
- Calendar confidence dampening cannot cross zero and accidentally reverse a weak directional score.
- Forward research observations retain calendar and price-source provenance without becoming live orders or automatically promoting an early-lock policy.

## Validation

- 46 automated tests and production build pass, including existing call integrity, position reconciliation, hourly records and shadow-study tests.
- Local Cloudflare runtime returns official BLS, BEA and Fed events and live public Kalshi markets. Calendar parsing was bounded to the relevant horizon and the timezone formatter reused to reduce cold-request CPU work.
- Isolated desktop / 390px mobile browser checks cover Overview, AutoTrade, Memory, Hourly, Signals, TradingView, News & macro, Analytics, Brain, Sports and Weather. All non-read HTTP requests were blocked; no credentials or test orders were entered.
- Simulated calendar and OKX outages display explicit unavailable states without application crashes. Existing third-party TradingView `cannot_get_metainfo` messages are separately recorded, not counted as Tara application errors.
- Research export contains source provenance. All 1,000 retained call records still retain their original decision evidence.

## Deliberate limits

- Free-source data is not a Bloomberg-equivalent service and has no guaranteed SLA or win rate. No claim of improved profitability is made without forward results.
- This calendar covers BLS, BEA and published Fed events, not every global event, claims/Census/Treasury release, exchange settlement or surprise headline. Guessed dates for unsupported events were removed rather than presented as confirmed schedules.
- Licensed CF BRTI is not connected. Kalshi's official settlement is still the outcome authority; a comparison price is not an official benchmark or a confirmed exchange fill.
- OpenBB is linked as an optional open-source research/integration tool, not installed as an unnecessary separate server. Koyfin and FRED open externally; no accounts were created.
- Stake sizes, account permissions, auto-trade arming, order execution and risk limits were not changed. Existing event-specific behavior now uses published schedules; added contextual speeches do not introduce a new trading gate.
